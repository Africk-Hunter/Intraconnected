Intraconnected on Android and iOS

One Capacitor shell around the existing web build. Android goes first because it builds on Windows with a USB phone. Every code change is shared, so iOS loses nothing by waiting. The app sells nothing.

Cold start in the app

A new NativeEntry component owns route / on native and keeps the splash up until it decides.

LaunchSplash stays visible
CheckFirst auth state + key from secure storage
Signed in, key foundlocation.replace('/main'). No login flash.
Signed in, key missingGo to /login to re-derive the key from the password.
Signed outGo to /login. No landing page, ever.

Account deletion, Terms and Privacy back buttons all end up at /login on native. Auth and Idea pages also hide the splash as a safety net.

Prerequisites

You, in parallel with Phase 1
You
  • Enroll in the Apple Developer Program as Individual ($99/yr, up to 48 h). Accept the App Store Connect agreements when the welcome email arrives.
  • Create the Play Console account ($25). Install Android Studio and turn on USB debugging on a phone.
  • Check the Firebase API key in Google Cloud Console for an HTTP-referrer restriction. If present, sign-in from the app fails until it is changed.

Auth and key storage

SharedHighest risk
  • firebaseConfig.ts: on native use initializeAuth with indexedDBLocalPersistence and no popup resolver. Web keeps getAuth.
  • dekStore.ts: on native, store the raw key in Keychain / Keystore. loadDEKFromSession becomes loadPersistedDEK; clearDEK becomes async and its callers await it. Web path unchanged.

Known risks, accepted for v1

iOS can evict WebView storage

Ideas re-download and the key survives in Keychain. Unsent offline edits and the Firebase login could be lost. Later fix: mirror the outbox to @capacitor/preferences.

Email links open in the browser

Verify and reset links finish on the web, then the user returns to the app. Universal / App Links come later.

Tablets

Android tablets at 1024px or wider get the desktop layout. iOS ships iPhone-only.

Unchanged

Sync layer, outbox, Firestore rules, encryption format and Stripe billing are shared with the web and not touched.
